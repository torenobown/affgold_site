AFFGOLD — демо-макет сайта

В архиве:
- index.html — главная
- catalog.html — каталог проектов
- review.html — страница обзора
- bonuses.html — страница бонусов
- css/styles.css — все стили, адаптив и анимации
- js/main.js — меню, табы, reveal-анимация, счётчики, активные чипы
- assets/images — svg-иллюстрации
- assets/icons — favicon

Как открыть:
1. Распакуйте архив.
2. Откройте index.html в браузере.
3. Для редактирования используйте любой редактор кода.

Особенности:
- адаптив под десктоп и мобильные устройства;
- тёмная дизайн-система;
- анимации hover/reveal/floating;
- нижнее меню на мобильной версии;
- готовая структура для интеграции в Figma или вёрстку под backend.
