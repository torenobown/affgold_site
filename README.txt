AFFGOLD — структура проекта

ОСНОВНЫЕ СТРАНИЦЫ
- index.html — главная страница
- catalog.html — динамический каталог с рабочими фильтрами
- reviews/ID/index.html — готовые HTML-обзоры с чистыми URL
- ratings/ — рейтинги по отдельным критериям
- bonuses/ — бонусные подборки
- providers/ — динамические страницы игровых студий
- payments/ — справочник по платёжным методам
- guides/ — информационные материалы
- about/ — методика, редакционная политика и ответственная игра
- sitemap.xml — карта сайта для поисковых систем
- robots.txt — правила индексации и ссылка на sitemap.xml

БАЗА ПРОЕКТОВ
Файл: js/projects-data.js

ПРОСТАЯ АДМИНКА
Адрес после запуска локального сервера:
http://localhost:8000/admin/

В админке можно:
- добавить проект через форму;
- изменить бонус, промокод, офферную ссылку и список игровых студий;
- загрузить логотип прямо в базу;
- удалить проект;
- сохранить черновик в браузере;
- скачать или записать готовый projects-data.js.

Публикация изменений:
1. В админке нажмите «Сохранить файл базы».
2. Сохраните его вместо js/projects-data.js.
3. Дважды нажмите rebuild-site.bat.
4. Загрузите обновлённую папку на хостинг.

Админка имеет noindex и сама не изменяет файлы на сервере: это безопасный
редактор базы без паролей и доступа к хостингу.

Все проекты хранятся в массиве window.AFFGOLD_PROJECTS.
Чтобы добавить новый проект:
1. Скопируйте один объект в массиве.
2. Укажите уникальный id.
3. Измените название, логотип, бонус, рейтинг, описание и остальные поля.
4. Выполните команду генерации, после чего обзор появится по адресу:
   reviews/SLUG/

ГЕНЕРАЦИЯ SEO-СТРАНИЦ
Команда:
node scripts/build-seo.mjs

Скрипт обновляет:
- статические обзоры;
- рейтинги и тематические страницы;
- страницы игровых студий;
- sitemap.xml.

Старые адреса compare/, news/, updates/ и about/authors/ сохранены только как
noindex-переходы на актуальные разделы и не включаются в sitemap.xml.

После любого изменения js/projects-data.js запускайте генератор заново.
В Windows можно просто дважды нажать rebuild-site.bat.

JAVASCRIPT
- js/main.js — общая логика сайта: меню, вкладки, анимации
- js/projects-data.js — база данных проектов
- js/catalog.js — поиск, фильтрация, сортировка и отрисовка каталога
- js/review.js — конструктор страницы обзора
- js/admin.js — добавление, редактирование и удаление проектов
- js/home-projects.js — карточки на главной из общей базы
- scripts/build-seo.mjs — генератор статических SEO-страниц и sitemap.xml

СТИЛИ
- css/styles.css — точка подключения всех CSS-файлов
- css/base.css — переменные, базовые элементы, шапка
- css/components.css — общие компоненты, футер и анимации
- css/home.css — главная страница и карточки
- css/catalog.css — каталог, таблица и фильтры
- css/review.css — страница обзора
- css/seo.css — статьи, рейтинги, подборки и страницы доверия
- css/responsive.css — общая адаптивность

ЗАПУСК
Для корректной работы рекомендуется запускать проект через локальный сервер.
В VS Code можно использовать расширение Live Server.
Либо выполнить в папке проекта:
python -m http.server 8000

После этого открыть:
http://localhost:8000/

ПЕРЕД ПУБЛИКАЦИЕЙ
Если основной домен отличается от https://www.affgoldprod.com, замените домен
в scripts/build-seo.mjs, canonical главной/каталога и robots.txt, затем снова
выполните node scripts/build-seo.mjs.
