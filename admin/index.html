Управление проектами

Добавляйте, изменяйте и удаляйте карточки через обычную форму. Черновик сохраняется в этом браузере.

Как опубликовать изменения

  1. Отредактируйте список и нажмите «Сохранить файл базы».
  2. Выберите существующий файл js/projects-data.js в папке проекта и подтвердите замену.
  3. Дважды нажмите rebuild-site.bat. После сообщения «Готово» загрузите проект на хостинг.

Node.js нужен только для пересборки SEO-страниц. Каталог и карточки используют ту же базу.
